## 1. 定位与参考

**一句话定位**：把「这个月的钱花成什么样」做成开机首页——KPI、预算弹药、6 月趋势、支出结构一屏读完，不需要一层层点进报表。

| 参考 | 借了什么 |
|---|---|
| Copilot Money（桌面） | KPI 卡 + 桌面级图表密度，用颜色区分「钱在往哪流」 |
| YNAB | 预算执行的「弹药感」：90.9% 已用、剩余 ¥592.10 必须让人心里一紧 |
| Monarch | 分类堆叠条 + 全案统一的分类色板 |
| Linear | 84px 图标栏的节奏与信息密度控制 |

**与另外三案的差异**：A 是表格、B 是卡片时间流、**C 是图表仪表盘**（本方案）、D 是暗色极简键盘流。

- **标题栏 40px**：仅放应用标识 + 账套 + 三个 46×40 窗口按钮热区（关闭 hover `#E81123`）。
- **图标栏 84px**：概览 / 流水 / 统计 / 预算 / 账户 + 底部设置；选中态 = 12px 圆角 `#EEF0FF` 底 + 左缘 3px 靛蓝竖条 + 10px 图标下文字，hover 出 tooltip（提示里带实时数据，如「预算 · 剩余 ¥592.10」）；底部放用户头像，承担「当前账套」入口。
- **页头 26px**：日期与账套是「我在看哪个账期」的锚；右侧橙色告警 pill（预算仅剩 ¥592.10）与 `＋ 记一笔` 主按钮，是全局唯一的强 CTA。
- **KPI 行 96px × 4**：支出 / 收入 / 结余 / 净资产。每张卡 = 标签 + 26px 主数字 + 环比脚注 + 右上角 24px 色块图标，四张卡等宽（320px），横向扫读有节奏。
- **图表区 570px**，左 1000 / 右 300：
  - 环形预算（380×278）：90.9% 用两段弧表达，前 70% 靛蓝、后 20.9% 琥珀，末端即「危险区」，配「接近超支」角标；下方三栏 预算 / 已支出 / 剩余。
  - 近 6 月趋势（606×278）：内联 SVG 面积折线，4 条网格线 + 6 个数据点 + 每点精确数值，本月点为靛蓝实心带光晕。
  - 分类堆叠横条（1000×278）：10 类按占比横向铺开，≥5% 的段内直接标注百分比；下方 5×2 图例列出金额与占比，底部一行给结论（住房+购物 80.7%）。
  - 右栏（300×570）：洞察提醒 338（4 条，每条 = 32px 色块图标 + 标题 + 一句可核验数字）+ 本月进度 218（4 行指标 + 90.9% 进度条）。
- **账户条 86px**：5 个账户 + 净资产，净资产用靛蓝浅底 pill 收尾，形成「从左到右累加出净资产」的阅读顺序。

**02-记一笔**：主界面压暗 55% + 720×556 居中弹层。录入顺序＝金额 → 分类 → 账户/日期 → 摘要/备注，金额是唯一带焦点环的元素（34px 数字 + 光标），分类用 10 个 chip，餐饮选中态用分类色（红）而非强调色，保证「分类色」语义不被强调色污染。

**03-统计**：图表密度最高的一页。页头放月份切换器（6–11 月）与维度切换器（分类/账户/标签）；主体两行 = 分类占比环形（440）+ 支出趋势与预算基准线（860）/ 分类排行条形（660）+ 收入支出对比双柱（642）。趋势图上把「预算 ¥6,500」画成虚线基准，9 月 ¥7,860 的点用红点标记「超预算」，把「预算」从抽象百分比变成可比较的线。

## 4. 交互与快捷键设想

1. **`Ctrl + N` / `N`**：任意页面呼出「记一笔」弹层，焦点直接落在金额，可直接键入数字。
2. **`Ctrl + Enter`**：弹层内保存；保存后弹层不关闭，金额清空、分类保留，实现「连记 3 笔」。
3. **`Esc`**：关闭弹层 / 退出下钻；遮罩本身也可点击关闭。
4. **`Ctrl + 1…5`**：概览 / 流水 / 统计 / 预算 / 账户，图标栏可点击，hover 出 tooltip（含实时数值）。
5. **`←` / `→`**（统计页）：切换月份；**`Shift + ←/→`**：切换维度（分类 / 账户 / 标签）。
6. **`Ctrl + K`**：全局命令面板（跳账户、跳月份、导出 CSV、删除上一笔）。
7. **`Ctrl + Z`**：撤销上一笔（5 秒内直接撤销，超时二次确认）。
8. **图表下钻**：hover 数据点 → tooltip 显示「9 月 ¥7,860.00 · 支出 23 笔 · 超预算 ¥1,360.00」；点击环形成分或排行条 → 下钻到该分类流水。
9. **`Alt + ↑/↓`**：流水列表逐行移动，`Enter` 打开详情，`Delete` 删除（可撤销）。
10. **窗口按钮**：46×40 热区，关闭 hover 变 `#E81123` 白字。

## 5. 优点 / 缺点 / 最适合人群

**优点**
- 一屏回答四个问题：花了多少、还剩多少、花在哪、走向如何，浏览决策成本最低。
- 数字负责精确、图表负责趋势，二者互相印证，比纯表格更快建立「月度体感」。
- 模块高度可复用：KPI 卡、环形、折线、堆叠条、提醒卡、账户条可独立复用到其它页面。
- 分类色板全案统一（10 色），流水、标签、图表共用一套语义，长期记忆成本低。
- 预算 90.9% 的「紧张态」做了三层表达（橙色 pill + 琥珀弧段 + 提醒卡），不会漏看。

**缺点**
- 图表最多 → **QML 实现成本最高的一案**（详见第 6 节），首版工作量约为 A 的 1.8 倍。
- 首屏信息密度大，新用户需要 1–2 天适应；建议首启加一次性引导（高亮 4 个 KPI）。
- 长期「接近超支」的视觉压力可能引起焦虑，需要「本月免打扰」开关。
- 只做了浅色主题；若后续要暗色，10 个分类色需整体降饱和重调，不是简单反色。
- 固定 1440 布局在窄窗口下需要重新断行（≥1280 可用）。

**最适合**：25–35 岁、每月固定复盘、在意「消费结构」而不只是「总数」的上班族；家庭账本也合适（多账户 + 净资产 + 房贷类大额支出是刚需）。不适合只想「3 秒记完就走」的人——那是方案 D。

## 6. QML 实现要点与风险

| UI 元素 | QML 实现方案 | 成本 | 风险 |
|---|---|---|---|
| 环形预算 | `Shape` + `ShapePath` + `PathAngleArc` 画两段弧（`startAngle:-90, sweepAngle:252` 靛蓝 → `162→237.24` 琥珀）。90.9%×360 = **327.24°** | 低 | 低：`PathAngleArc` 的 0° 在 3 点钟方向、顺时针为正，等价于设计稿 `rotate(-90)`；`strokeWidth` 需配合 `fillColor:"transparent"` |
| 面积折线 | 首选 `Shape { ShapePath { PathSvg { path: "M52 105 L152 98 …" } } }`，SVG 的 `d` 字符串可 1:1 搬；数据驱动时用 `Canvas` + `lineTo` 拼点 | 中 | 渐变面积填充在 `ShapeGradient` 上各版本支持不一 → 兜底用 `Canvas` 或降级为纯色 12% 透明填充 |
| 网格线 / 数据点 | `Repeater` + 1px `Rectangle`（网格）+ 8px `Rectangle { radius:4 }`（点） | 极低 | 无 |
| 分类堆叠条 | `RowLayout` + `Repeater`，`Layout.preferredWidth = totalW * pct/sum − spacing` | 极低 | 段太窄（<8px）时别再画圆角和内文，只留色块 |
| 分类排行条形 | 底轨 `Rectangle` + 内部 `Rectangle`（宽度 = 父宽 × ratio） | 极低 | 无 |
| 收支对比双柱 | `RowLayout` + `Repeater` + `Rectangle` 高度按比例 | 极低 | 需固定 baseline，避免按数据自动缩放造成视觉误导 |
| 卡片阴影 | `MultiEffect { shadowEnabled:true; shadowBlur:0.3 }` | 中 | **本方案最大性能风险**：20+ 张卡每帧离屏渲染。建议降级为「1px 描边 + 底部 1px 淡线」，only 弹层用 MultiEffect |
| 金额等宽数字 | `Text { font.features: {"tnum": 1} }`（Qt 6.5+ 支持 OpenType feature；Qt 6.11 无问题） | 低 | 若字体缺 `tnum`，兜底换 `Consolas`，视觉会变但不破坏对齐 |
| 图标 | `Shape { ShapePath { PathSvg { path:"M…" } } }`（描边式，最贴合设计稿 `stroke 1.6`）或 `Image{source:"qrc:/icons/*.svg"}`（需 Qt SVG 模块） | 低 | 内联 SVG 文本无法直接渲染，必须转 `PathSvg` 或预渲染资源 |
| 数据下发 | `QAbstractListModel`（CategoryModel：name/amount/pct/color），图表全部 `Repeater` 绑定 | 低 | **派生值（环比、均值、结余率）必须在 C++ 算好**，QML 不做浮点运算，避免 UI 出现 68.49999% |

**其它落地建议**
- 弹层用 `Popup { modal:true; dim:true }` + `Rectangle` 遮罩，`dim` 的默认遮罩色与设计稿 `rgba(15,18,24,.55)` 接近，微调 `Overlay.modal.color` 即可。
- 图表坐标不要写死：抽 `plotWidth / plotHeight / yMin / yMax` 四个变量，窗口缩放时用 `onWidthChanged` 重算 path 字符串。
- 建议最小窗口 1280×800；小于此宽度时图表区改为纵向堆叠。
- 环形/折线的入场动画用 `NumberAnimation` 驱动 `sweepAngle` / `progress`（200–300ms，`Easing.OutCubic`），比逐帧 Canvas 便宜得多。
