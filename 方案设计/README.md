# 小账本 · 桌面记账软件 UI 方案设计（Qt 6 + C++20）

> 本文档集为「Windows 桌面记账软件」的完整 UI 方案设计 + 技术开发计划。
> 技术栈：**Qt 6.11 + C++20 + Qt Quick/QML + SQLite**，目标平台 Windows 10/11。
> 4 套 UI 方案由同一份数据字典驱动、同一 1440×900 画布、同样 3 张界面，可直接横向对比。

---

## 一句话结论

**推荐：方案 A「经典财务工作台」作为主骨架，融合 C 的图表洞察、D 的键盘流、B 的柔和视觉配额，形成定稿（`08-推荐方案原型/`）。**

理由：记账软件的第一价值是"可核对"——A 是唯一做到"分类·时间·摘要·账户·金额"五列同行、任意一笔可横向扫读的方案；
且它是四套里 QML 落地成本最低的，同时能低成本演进成其它三套的气质。详见 [06-方案对比与推荐.md](06-方案对比与推荐.md)。

```
方案设计/
├─ README.md                        ← 本文件
├─ 01-市场调研与设计启示.md           ← 10 款竞品分析 + 12 条设计启示 + Qt6 交互清单
├─ 02-方案A-经典财务工作台/           ← 推荐骨架
│   ├─ 01-主界面.html / .png
│   ├─ 02-记一笔.html / .png
│   ├─ 03-统计.html / .png
│   └─ 设计说明.md                   ← token 表 + ASCII 架构 + QML 组件树 + 风险
├─ 03-方案B-卡片时间流/
├─ 04-方案C-数据驾驶舱/
├─ 05-方案D-极简速记暗色/
├─ 06-方案对比与推荐.md               ← 加权评分 + 逐维度深挖 + 定稿配方 + 验收清单
├─ 07-开发计划-Qt6与C++20.md         ← 架构/DB DDL/里程碑 M0–M5/风险/现状体检
├─ 08-推荐方案原型/                   ← 定稿：4 张界面 + Theme.tokens.json + 组件规格
└─ _shared/
    ├─ 设计基准.md                   ← 共用数据字典、画布规范、质量红线（4 套方案的唯一事实来源）
```

每套方案目录内的 `设计说明.md` 均包含：定位与参考软件、ASCII 信息架构图、design token 表（色板/字号/圆角/间距/尺寸，可直接翻成 QML）、快捷键设想（≥6 条）、优缺点与适用人群、QML 实现要点与风险。

## 如何重新出图（可选）

设计稿是单文件 HTML（内联 CSS + 内联 SVG，无任何外部依赖），可直接用浏览器打开。

```powershell
# 重新生成某张 PNG（需要 Chrome 或 Edge）
powershell -NoProfile -ExecutionPolicy Bypass -File "方案设计\_shared\shoot.ps1" `
  -Html "D:\STUDY\C++_QT\Keep_account\方案设计\02-方案A-经典财务工作台\01-主界面.html" `
  -Out  "D:\STUDY\C++_QT\Keep_account\方案设计\02-方案A-经典财务工作台\01-主界面.png"
```

> 本机是 PowerShell 5.1：含中文的 `.ps1` 必须存为 UTF-8 **带 BOM**；HTML/MD 存 UTF-8 无 BOM。
> 详见 `_shared/设计基准.md` 第 11 节。
