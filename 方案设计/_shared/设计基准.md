# 设计基准（所有 UI 方案共用，必须逐字遵守）

> 这份文件是 4 套 UI 方案的**唯一事实来源**。所有方案的演示数据、画布尺寸、文案口径、交付规范必须与本文一致，
> 这样 4 套方案才能横向对比。任何"自创数据"都算不合格。

---

## 1. 产品背景

- 产品：Windows 桌面记账软件（个人 / 家庭记账）
- 目标用户：25-35 岁、有记账习惯、关注月度预算与消费结构、能接受键盘操作的上班族
- 技术栈（本次不作为设计约束，但设计要给实现留余地）：**Qt 6.11 + C++20 + Qt Quick/QML + SQLite**
- 设计稿用途：先定风格与信息架构，选定方案后由 C++/QML 实现

**因此：设计稿尽量少用 Qt 上实现成本过高的效果**（例如大范围 backdrop-filter 毛玻璃、复杂 CSS grid 嵌套、
运行时高斯模糊叠加）。阴影、圆角、渐变、内联 SVG 图标都可以。若使用高成本效果，在该方案的"设计说明.md"里标注出来。

## 2. 画布规范（强制）

| 项目 | 规格 |
|---|---|
| 画布尺寸 | **1440 × 900**，`html,body { width:1440px; height:900px; overflow:hidden; margin:0 }` |
| 缩放 | 100%，截图必须正好 1440×900，不允许出现滚动条、不允许内容溢出被裁切 |
| 窗口形态 | 桌面应用窗口，**自绘标题栏 40px 高**：左侧应用图标 + 标题，右侧最小化 / 最大化 / 关闭三个按钮 |
| 标题栏按钮 | 46×40 的矩形热区，关闭按钮 hover 态为红底（#E81123）白字，未 hover 时无背景 |
| 窗口边框 | 1px 描边模拟窗口边缘；**不要**画 Windows 11 的圆角窗口（截图方角即可），也不要画浏览器地址栏 |
| 系统缩放 | 按 1x（96 DPI）出图 |

## 3. 字体与排版

- 字体族：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif`
- 数字：`font-variant-numeric: tabular-nums;`，金额右对齐，千分位逗号，两位小数，货币符号 ¥
- 字号阶梯（基准）：11 / 12 / 13 / 14 / 16 / 20 / 24 / 32 / 40 px
- 正文行高 1.5；标题行高 1.25；字重只用 400 / 500 / 600 / 700
- 中文文案一律中文全角标点（，。：；「」），不要机翻感
- 禁止 lorem ipsum、禁止 "Item 1 / 标题占位" 这类占位文案

## 5. 每个方案必须交付的 3 张界面

| 文件 | 界面 | 要求 |
|---|---|---|
| `01-主界面.html` | 应用主界面（首页） | 必须能一眼看出该方案的核心主张；导航 + 流水 + 关键指标齐全 |
| `02-记一笔.html` | 新增一笔（录入态） | 输入框**已填写**示例：分类=餐饮、金额=23.00、账户=支付宝、日期=2026-11-11、摘要=午餐 · 沙县小吃；呈现"已填好待保存"的完整状态（不要空表单） |

每个 `.html` 必须是**单文件自包含**（CSS 内联在 `<style>`，图标用内联 `<svg>`），不引用任何外部 CDN、字体或图片。
`02-记一笔.html` 建议把主界面压暗（如 `rgba(15,18,24,.55)` 遮罩）+ 悬浮录入面板，这样更有"录入态"的真实感。

## 6. 图标规范

- 全部用**内联 SVG**：24×24 视框，`fill=none`，`stroke=currentColor`，`stroke-width=1.6`，`stroke-linecap=round`
- 不允许用 emoji 代替图标（跨机器渲染不一致）
- 允许用 1-2 个字母的圆形分类徽标（如"住"、"食"）作为分类图标，但同一方案内规则要统一

## 11. 本机工具链事实（务必遵守，否则会踩坑）

1. 本机是 **Windows PowerShell 5.1**，命令是 `powershell`，**没有 `pwsh`**。
2. 写含中文的文件必须走 .NET，别用 `Set-Content -Encoding utf8`：

```powershell
$content = '@
...文件内容...
'@
[System.IO.File]::WriteAllText("D:\...\01-主界面.html", $content, (New-Object System.Text.UTF8Encoding($false)))
```

   追加写入用 `[System.IO.File]::AppendAllText($path, $chunk, (New-Object System.Text.UTF8Encoding($false)))`。
   - HTML / MD → UTF-8 **无 BOM**
   - 自己写的 .ps1（含中文）→ 必须 UTF-8 **有 BOM**（`New-Object System.Text.UTF8Encoding($true)`），
     否则 5.1 按 GBK 解码，中文字符会吞掉后面的引号，直接语法错误。
3. 单条 shell 命令过长可能被截断：**一个 HTML 分 2~3 段写**（第一段 WriteAllText，后续 AppendAllText）。
4. **读文件用 `read` 工具**，不要用 `Get-Content`（5.1 默认 GBK 解码，中文显示成乱码，容易误判）。
5. 截图的可靠调用方式（脚本已备好并验证过）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\STUDY\C++_QT\Keep_account\方案设计\_shared\shoot.ps1" -Html "D:\STUDY\C++_QT\Keep_account\方案设计\02-方案A-经典财务工作台\01-主界面.html" -Out "D:\STUDY\C++_QT\Keep_account\方案设计\02-方案A-经典财务工作台\01-主界面.png"
```

   成功会打印 `OK  1440x900  22,656 bytes  -> ...`；若打印 `SIZE MISMATCH` 说明页面高度溢出，必须回去改 HTML。
6. 出图后**用 `read_image` 亲自看**，确认无裁切/无重叠/无溢出，再做下一张。
