## 修复 Android Studio 报「Could not install Gradle distribution ... Connection refused」

- 根因：`services.gradle.org` 国内直连被拒；且工程缺 `gradlew` / `gradle-wrapper.jar`，Android Studio 只能自己下载发行包。
- 修复三件事：
  1. `gradle-wrapper.properties` 的 `distributionUrl` 改为腾讯云镜像 `https://mirrors.cloud.tencent.com/gradle/gradle-8.9-bin.zip`（阿里云无 gradle 目录，华为云 `https://mirrors.huaweicloud.com/gradle/` 可作备选）。
  2. 预热 Gradle wrapper 缓存：`~/.gradle/wrapper/dists/gradle-8.9-bin/78qddjpeqn5v6yec3xb8kv9ca/`（hash = base36(md5(url))），已解压 `gradle-8.9/` 并写入 `.ok` 标记，Studio 直接命中不再下载。
  3. 用 Studio 自带 JBR 21 + 预热发行包执行 `gradle wrapper --gradle-distribution-url <镜像>` 生成 `gradlew` / `gradlew.bat` / `gradle-wrapper.jar`。
- 顺带：`settings.gradle.kts` 的 pluginManagement / dependencyResolutionManagement 均把阿里云镜像排在 google()/mavenCentral() 之前。
- 已实测构建通过：`./gradlew :app:assembleDebug` → BUILD SUCCESSFUL，产物 `app/build/outputs/apk/debug/app-debug.apk`（9.7 MB）；AGP 自动补装了 build-tools 34.0.0 与 platform android-35。
- 本机环境备忘：Android Studio 在 `D:/Program Files/Android_Studio`（JBR 21 在 `jbr/bin/java.exe`），SDK 在 `C:/Users/ren/AppData/Local/Android/Sdk`；无 AVD、无 system-images，无法起模拟器截图。

## 在 MuMu 模拟器上做像素级还原度核对

- MuMu 15 安装在 `D:/Program Files/Netease/MuMu`，实例 0 的 ADB 端口来自 `vms/MuMuPlayer-15.0-0/configs/vm_config.json` → `nat.port_forward.adb.host_port = 16384`；未启动时 16384 不监听，用 `MuMuManager.exe control -v 0 launch` 启动（`info -v 0` 看 `is_android_started`）。
- 关键：`adb shell wm size 1080x2340 && wm density 440` → 屏幕正好 393×852dp，App 的等比缩放系数 =1.0，截图可与设计稿 1:1 比对；用完 `wm size/density reset`。
- Git Bash 下 adb 的设备路径 `/sdcard/...` 会被 MSYS 转换，必须 `export MSYS_NO_PATHCONV=1`，且 pull 的目标要用 Windows 路径。
- 设计稿导出用 `export_nodes` scale=1，得到 481×958（含 44px 阴影外扩），裁 `(44,44,437,896)` 得 393×852；比对时用 RGBA alpha 遮罩排除 40dp 屏圆角的透明区。
- 指标：4px 高斯模糊后 |design-app| 均值。修复后 7 屏平均 **3.5/255（98.6%）**：01 3.9、02 3.1、03 2.3、04 5.5、05 4.4、06 3.0、07 2.0。
- 核对中发现并修复的 4 处真实偏差：
  1. `SystemIcons` 用设计稿 0-68 坐标当像素画，高密度屏上图标只有 1/2.75 且贴左 → 加 `scale(size.width/68f)`。
  2. 首页预算卡金额与进度条之间多 `Spacer(7.dp)` → 整卡高 8dp，下方全部下移；删掉。
  3. 分类管理内容区多 `Spacer(10.dp)` → 列表下移 11dp；删掉（该屏均差 6.6→2.0）。
  4. 账户页净资产卡 `Spacer(14.dp)` → 偏高 5dp；改 9.dp（6.6→3.0 系误记，实为 5.7→3.0）。
- 剩余差异主要是字形：设计稿导出用服务端字体，App 用 Roboto + Noto Sans CJK；要做 100% 需内置 Inter / Noto Sans SC。
- 产出：`XIAOMAN_Android/verify/`（7 张三联图 + overview.png + README 报告）。
