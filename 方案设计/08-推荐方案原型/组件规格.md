# 定稿组件规格（QML 落地清单）

> 配套：`Theme.tokens.json`（色/字号/圆角/间距/尺寸的唯一来源）、`01-主界面.png` ~ `04-命令面板.png`（视觉基准）。
> 约定：**组件内不得硬编码色值与尺寸**，一律走 `Theme`。下表「尺寸」均为 1440×900 @1x 的 px 值。

## 0. 组件树

```
ApplicationWindow (FramelessWindowHint)
├─ TitleBar                 40px   [图标 账本名 用户 ─ □ ✕]
├─ ToolBar                  56px   [MonthSwitcher SearchField FilterButton CommandEntry PrimaryButton]
├─ RowLayout (主体)
│  ├─ NavRail               248px  [NavItem ×7 / AccountRow ×5 / CategoryRow ×3 / BudgetCard]
│  ├─ ColumnLayout (1fr)    工作台页：KpiCell ×5 → ColumnHeader → TransactionList → KeyHintBar
│  │                        概览页：  KpiCard ×4 → BudgetRing + AreaTrend → StackedBar + InsightList
│  └─ DetailPane            352px  [金额/分类/日期/账户/备注/标签/同类统计/操作按钮]
└─ Overlay
   ├─ EntryPanel            860×620 [CategoryCircleStrip / 账户 / 日期 / 备注 / 金额 / Keypad / 余额预览]
   ├─ CommandPalette        640×~560 [命令分组列表]
   └─ Scrim                 全屏    rgba(15,18,24,.55)
```

## 2. 实现优先级（与 07 开发计划对齐）

| 阶段 | 组件 | 理由 |
|---|---|---|
| M1 | 1–8（窗口 / 标题栏 / 工具条 / 按钮类） | 骨架先跑起来，`Theme` 同时落地 |
| M1 | 9–19（导航 / 表格 / 状态条） | 主界面可交互、可核对，是本产品的地基 |
| M2 | 20–21（详情栏）+ 26–28（录入面板） | 完成「选中→看详情→记一笔」闭环 |
| M3 | 22–25（概览页图表） | 4 个固定图表自绘，`Shape`/`Canvas`，不引 Qt Charts |
| M4 | 29（命令面板）+ 键位统一 | D 的加速层，最后加不破坏骨架 |
| M5 | 暗色主题（`colors.dark`） | 只换色板，布局零改动 |

## 3. 已知实现风险（对应 06 §9 ADR）

1. **自绘标题栏**：拖动 / 双击最大化 / 贴边分屏需自行实现（`window.startSystemMove()` + `MouseArea.onDoubleClicked`）。
2. **左侧 2px 选中条**：不要用 `border.left`（会改变内容宽度导致行内列宽抖动），用行内叠一个 `width:2` 的 `Rectangle` 或 `Rectangle` 的 inset 边框。
3. **数值列对齐**：`Text` 必须 `horizontalAlignment: Text.AlignRight` + `font.features: {"tnum": 1}`，否则金额滚动时左右跳动。
4. **面积图**：`Shape` 的 `PathPolyline` 只负责折线，渐变填充需 `ShapePath` + `LinearGradient`（`Shape` 支持 `fillGradient`）；坐标换算建议放 C++ `Q_PROPERTY` 算好再喂给 QML，避免 QML 里做浮点运算。
5. **Popup 层级**：`CommandPalette` 与 `EntryPanel` 互斥，用 `Overlay.overlay.modal` 或统一一个 `AppOverlay` 管理，避免两个 `Popup` 同时打开抢焦点。
