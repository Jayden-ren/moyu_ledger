## 3. 实现顺序建议

1. **先落 `Theme`**：把 `Theme.tokens.json` 生成为 `Theme.qml`（`pragma Singleton`），并加一条 `qmllint` 规则禁止组件内硬编码色值。
2. **M1 · 骨架**：`AppWindow` → `TitleBar`（自绘 + 拖动/双击最大化）→ `ToolBar` → `NavRail`。
3. **M1 · 地基**：`KpiCell` → `ColumnHeader` → `TransactionList`（`ListView` + `section` 分组头 + 固定行高开 `reuseItems`）→ `KeyHintBar`。到这一步「能看能选」。
4. **M2 · 闭环**：`DetailPane`（绑定 `ListView.currentItem`）→ `EntryPanel` + `Keypad` + `CategoryCircleStrip`。到这一步「能记能改」。
5. **M3 · 洞察**：`BudgetRing` → `AreaTrendChart` → `StackedBar` → `InsightRow`（`Shape`/`Canvas` 自绘，**不引 Qt Charts**，见 ADR-2）。
6. **M4 · 加速层**：`CommandPalette` + 全局 `Shortcut`，并核对「状态条 / 命令面板 / tooltip」三处键位一致（06 §8 验收清单）。
7. **M5 · 暗色**：只切 `colors.dark`，布局与尺寸零改动。
